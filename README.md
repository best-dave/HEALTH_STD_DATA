# Health STD Data Analysis

## Project Overview
This project analyzes sexually transmitted disease (STD) data across different states and years.
The goal is to understand the distribution of STD cases, identify patterns across diseases and states, and examine the relationship between STD cases and population.

## Tools Used
* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## Analysis Performed
* Data cleaning and preparation
* Analysis of total STD cases
* Comparison of STD cases by disease
* Analysis of STD cases by state
* Analysis of STD trends over time
* Population and STD case analysis
* Calculation of disease rates
* Data visualization

## Visualizations
The project includes visualizations showing:
* Percentage of cases by disease
* Relationship between STD cases and population
* Top states with STD cases
* Total STD cases by disease
* STD case trends over the study period

## Project Files
* `health_STD_cases.ipynb` — Python analysis notebook
* `STD Cases.csv` — Dataset used for the analysis
* PNG files — Data visualizations

## Conclusion
This project demonstrates how Python can be used to clean, analyze, and visualize public health data.
The analysis helps show differences in STD cases across diseases, states, and years and demonstrates the use of data analysis techniques for public health research.
